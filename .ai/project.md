# Project

**Name**: monorepo
**Repo**: github.com/marcslopz/monorepo
**Purpose**: Reusable full-stack app template. FastAPI backend (hexagonal architecture) + React/Vite frontend.

Each app lives under `backend/<app>` and `frontend/<app>`. Example app: `demo` (minimal Item CRUD).

Exception: `frontend/mananettis` — rehearsal prompter for a theatre class (static HTML + Cloudflare Pages
Functions + D1, no backend app). See `.ai/mananettis.md`.
